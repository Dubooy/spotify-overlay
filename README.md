# Isla

Tu música en una isla flotante arriba de la pantalla, al estilo Dynamic Island, para Windows 10/11.

- Funciona con lo que suene en tu PC: Spotify, YouTube en el navegador, Apple Music, SoundCloud…
- Sin cuentas, sin login, sin configurar nada: instalar y listo.
- Pasa el ratón por encima para abrirla. Clic derecho en el icono de la bandeja para cambiar entre **Isla** y **Burbuja**, elegir skin o salir.

## Descargar

Última versión: [Releases](../../releases/latest) → `Isla-Setup-x.y.z.exe`.

> Windows puede avisar de que la app no está firmada: "Más información" → "Ejecutar de todas formas".

## Cómo se construye

Cada cambio en `main` lo construye GitHub Actions en Windows y publica el instalador en Releases automáticamente (`.github/workflows/build.yml`).
